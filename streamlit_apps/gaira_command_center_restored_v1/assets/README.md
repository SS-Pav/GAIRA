# assets

Static assets for the GAIRA Command Center.

Currently empty — the app loads images / tables / reports directly from
`/Volumes/SSD_Rad/GAIRA_BUILD/<phase>/...` via the artifact manifest.

If a curated demo asset (logo, custom diagram, frozen exemplar figure)
needs to ship with the app, place it here and reference via
`streamlit_apps/gaira_command_center/assets/<filename>`.
